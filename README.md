# 🗓️ New Tab Extension - تقویم و آب‌وهوای لار

یک **Chrome Extension** که صفحه New Tab مرورگر را با یک داشبورد زیبا شامل **تقویم شمسی** و **آب‌وهوای لحظه‌ای شهر لار (فارس)** جایگزین می‌کند.

## 🧠 معماری (۴ لایه)

### ۱. Chrome Extension Layer
فایل `manifest.json` به مرورگر می‌گوید که این یک extension است و باید صفحه New Tab را با `index.html` ما جایگزین کند.

### ۲. Service Layer (لایه سرویس)
- **weatherService.js**: ارتباط با API خارجی OpenWeatherMap. مختصات جغرافیایی لار (`27.6746, 54.3429`) در آن ذخیره شده. دو تابع دارد: `fetchCurrentWeather()` برای هوای فعلی و `fetchForecast()` برای پیش‌بینی ۵ روزه.
- **calendarService.js**: الگوریتم کامل تبدیل تاریخ میلادی به شمسی (جالالی) با پشتیبانی از سال کبیسه. همچنین توابعی برای گرفتن نام ماه‌ها، روزهای هفته، و تولید جدول گرید ماه.

### ۳. State Management Layer (Hooks)
- **useWeather.js**: سه حالت `loading`, `error`, `success` را مدیریت می‌کند. در صورت خطا، دکمه retry ارائه می‌دهد.
- **useCalendar.js**: تاریخ امروز، ماه و سال جاری، و گرید روزهای ماه را نگه می‌دارد. دکمه‌های قبل/بعد و امروز را هندل می‌کند.

### ۴. Presentation Layer (کامپوننت‌ها)
- **Dashboard.jsx**: چینش کلی صفحه شامل هدر (greeting + ساعت) و دو کارت کنار هم
- **CalendarWidget.jsx**: جدول ۷ ستونه با روزهای هفته، هایلایت روز جاری، جمعه‌ها قرمز
- **WeatherWidget.jsx**: نمایش دما، شرایط جوی، جزئیات (رطوبت، باد، max/min)، و پیش‌بینی

## 🌟 ویژگی‌های UI/UX

- **حالت‌های مختلف نمایش**: لودینگ (اسپینر)، خطا (با دکمه تلاش مجدد)، و داده
- **Greeting هوشمند**: صبح بخیر / ظهر بخیر / عصر بخیر / شب بخیر بر اساس ساعت سیستم
- **Glassmorphism**: کارت‌های شیشه‌ای با افکت blur
- **Hover Effects**: کارت‌ها با hover رنگ عوض می‌کنند
- **Responsive**: در صفحه‌های کوچک layout به تک ستونه تبدیل می‌شود
- **RTL کامل**: پشتیبانی از راست‌به‌چپ فارسی
- **Edge Cases**: تغییر ماه در لبه سال، سال کبیسه، روزهای خالی ابتدای ماه

## 📦 نحوه نصب و اجرا

### پیش‌نیازها
- Node.js (نسخه ۱۸ یا بالاتر)
- npm (همراه Node نصب می‌شود)

### مراحل

```bash
# ۱. کلون کردن پروژه
git clone https://github.com/alimizh/Weather-and-Calendar.git
cd Weather-and-Calendar

# ۲. نصب وابستگی‌ها
npm install

# ۳. بیلد پروژه
npm run build

# ۴. نصب روی کروم
#    ۱. به chrome://extensions بروید
#    ۲. Developer mode را فعال کنید
#    ۳. Load unpacked را بزنید
#    ۴. پوشه dist را انتخاب کنید
```

### توسعه محلی
```bash
npm run dev
```
سپس مرورگر را باز کنید و به آدرس `http://localhost:5173` بروید.

## 🔑 تنظیم API Key

برای دریافت اطلاعات آب‌وهوا نیاز به کلید رایگان OpenWeatherMap دارید:

1. به [openweathermap.org](https://openweathermap.org/) بروید و ثبت‌نام کنید
2. از بخش API Keys یک کلید بگیرید
3. فایل `src/services/weatherService.js` را باز کنید و مقدار `API_KEY` را با کلید خود جایگزین کنید

```javascript
const API_KEY = 'Your_API_Key_Here'
```

> ⚠️ توجه: کلید فعلی (`f44563e05b7d08b6d02269031ca6cca6`) در این پروژه قرار داده شده است. در صورت نیاز می‌توانید آن را تغییر دهید.
